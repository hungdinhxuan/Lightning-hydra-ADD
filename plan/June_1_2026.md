# Generator Inventory (TTS/VC) — Training & Eval Data

## Mục tiêu

Trích xuất danh sách **generator** (TTS/VC/synthesizer) được gắn nhãn `spoof` từ training và evaluation protocol, xuất ra 2 file CSV:

| File | Nguồn dữ liệu |
|---|---|
| `reports/generator_inventory/train_generators.csv` | Training protocol — subset **`train` + `dev` only** |
| `reports/generator_inventory/eval_generators.csv` | Eval benchmark `/data/add_eval_data` **+** training protocol subset **`eval`** |

Format mỗi dòng:

```csv
generator,dataset,subset,count
```

Ví dụ:

```csv
Llasa-1B-Multilingual,MLAAD_v7,eval,18000
OmniVoice,April_Synthesizers,train,43095
a01,2025_Kipot,eval,25701
```

---

## Phạm vi dữ liệu

### Training (`train_generators.csv`)

- Nguồn: `data/dsd_corpus_pool_13May2026/15_May_full.txt`
- Subsets: `train`, `dev`
- Subset `eval` **không nằm ở đây** — chuyển sang `eval_generators.csv`
- Cột `dataset` = path level-1 (e.g. `MLAAD_v6`, `FEB_dataset`, `April_Synthesizers`)

### Eval (`eval_generators.csv`)

Gồm **2 nguồn**:

1. **Eval benchmark** — `/data/add_eval_data/*/protocol.txt`
   - `dataset` = tên folder benchmark (e.g. `MLAAD_v7`, `2025_Kipot`, `german_dataset_May262026`)
2. **Training eval subset** — dòng `eval spoof` từ `15_May_full.txt`
   - `dataset` = path level-1 (e.g. `MLAAD_v7`, `April_Synthesizers`)
   - Cùng generator + dataset + subset sẽ **cộng dồn** nếu xuất hiện ở cả 2 nguồn

## Quy tắc trích xuất generator

Script: `scripts/utils/extract_generators.py` — hàm `extract_generator(rel_path)`.

| Rule | Pattern | Ví dụ path | Generator |
|---|---|---|---|
| 1 | `.../fake/<lang>/<generator>/<file>` | `fake/de/Llasa-1B-Multilingual/a.wav` | `Llasa-1B-Multilingual` |
| 2 | `tts-output/<generator>/...` | `tts-output/chatterbox/.../sample.wav` | `chatterbox` |
| 3 | `April_Synthesizers/<generator>/...` | `April_Synthesizers/OmniVoice/tts/.../de/000.wav` | `OmniVoice` |
| 4 | `FEB_dataset/Synthesizers/<generator>/...` | `FEB_dataset/Synthesizers/VITS/file.wav` | `VITS` |
| 5 | `FEB_dataset/<category>/...` | `FEB_dataset/asvspoof2021_la_eval/x.wav` | `asvspoof2021_la_eval` |
| 6 | `2026_April_Dataset_Jiwon_collected/<generator>/...` | `.../WAN/1/1_1.wav` | `WAN` |
| 7 | `2025/eval/<attack_id>/...` | `2025/eval/a01/1001/1.wav` | **`a01`** (attack type) |
| 8 | Fallback | bất kỳ path nào khác | parent directory của file |

## Cách chạy

```bash
# Cả train + eval (eval CSV gồm benchmark + training eval subset)
.venv/bin/python scripts/utils/extract_generators.py --mode all \
  --protocol data/dsd_corpus_pool_13May2026/15_May_full.txt \
  --eval-root /data/add_eval_data \
  --output-dir reports/generator_inventory

# Chỉ training (train/dev)
.venv/bin/python scripts/utils/extract_generators.py --mode train \
  --protocol data/dsd_corpus_pool_13May2026/15_May_full.txt \
  --output reports/generator_inventory/train_generators.csv

# Chỉ eval benchmark (không gồm training eval subset)
.venv/bin/python scripts/utils/extract_generators.py --mode eval \
  --eval-root /data/add_eval_data \
  --output reports/generator_inventory/eval_generators.csv

# Eval benchmark + training eval subset
.venv/bin/python scripts/utils/extract_generators.py --mode eval \
  --protocol data/dsd_corpus_pool_13May2026/15_May_full.txt \
  --eval-root /data/add_eval_data \
  --output reports/generator_inventory/eval_generators.csv
```

### Validation

```bash
.venv/bin/python -m pytest tests/test_extract_generators.py -v

# train CSV không có subset eval
grep ',eval,' reports/generator_inventory/train_generators.csv
# → (empty)

# Kipot attack IDs
grep '2025_Kipot' reports/generator_inventory/eval_generators.csv
# → a01..a08

# Training eval subset đã chuyển sang eval CSV
grep ',MLAAD_v7,eval,' reports/generator_inventory/eval_generators.csv
```
