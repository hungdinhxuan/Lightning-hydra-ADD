## Example training script
- Có thể cần sửa lại datadir để match với training script bởi vì train/dev subset bây giờ đang nằm rời rạc ở 
data/add_processed_vad_short_eval10k_per_dataset_train80k_dev10k_29May2026/train
data/add_processed_vad_short_eval10k_per_dataset_train80k_dev10k_29May2026/dev
```bash
python scripts/run_training_gate.py \
  experiment=xlsr_conformertcm_mdt_lora_optimized \
  ++data.data_dir=<data_root_location> \
  ++data.args.protocol_path=<data_root_location>/protocol.txt \
  ++model.is_base_model_path_ln=False \
  ++model.base_model_path="/NAS1_pretrained_lab/May_21_2026_TCM_MDT.pt"
  logger=csv 
```
